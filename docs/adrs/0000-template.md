# NNNN: Short title of the decision

- **Status:** accepted <!-- or: superseded by [NNNN](NNNN-short-slug.md) -->
- **Date:** YYYY-MM-DD

## Context

What made us decide: the request, the problem, or the limit we ran into. A few sentences on how things stood and what held us back. Link to the code or docs involved. Write this after the decision is made. It's a record, not a plan for a pull request.

## Decision

What we decided, in one or two sentences. Often it's a "no": we won't build something, and the record names what already covers the need.

## Consequences

What stays simple, and what gets harder. Keep it short: a few bullet points or sentences.

**Revisit if:** what would make us look at this decision again.

---

Write a record when someone changing the code later might ask "why is it like this?" and the code can't answer. Don't write one just to note that a change shipped: git history already does that.
